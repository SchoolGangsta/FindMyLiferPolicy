Common questions

Discovery isn't finding any lifers nearby

Try increasing the search radius or days-back window from the location chip on the Discover tab. Recent sightings depend entirely on what other birders have reported to eBird in your area — sparse regions will naturally show fewer results.

My life list count looks wrong after importing

Make sure you imported MyEBirdData.csv from ebird.org/downloadMyData. eBird sends this as a .zip — tap it in the Files app to extract the CSV automatically, then import that file from Settings.

Bird photos aren't loading

Photos are sourced from the public iNaturalist API and require a network connection. If you're offline, the app shows a placeholder until you reconnect.

Where does the sighting data come from?

Live sightings come from the eBird API (Cornell Lab of Ornithology). FindMyLifer is an independent app and is not produced by or affiliated with the Cornell Lab.

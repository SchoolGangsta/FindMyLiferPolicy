# FindMyLiferPolicy

Hosts the public privacy policy for [FindMyLifer](https://github.com/SchoolGangsta/FindMyLifer), an iOS birding app, via GitHub Pages.

Live at: https://schoolgangsta.github.io/FindMyLiferPolicy/

The source of truth for this policy's content is [`PRIVACY.md`](https://github.com/SchoolGangsta/FindMyLifer/blob/main/PRIVACY.md) in the main app repo — `index.html` here is the styled HTML mirror that App Store Connect and in-app links point to. Update both together.
